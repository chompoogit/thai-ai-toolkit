# Thai AI Toolkit 🇹🇭🤖

Open-source AI tools designed to help people work with Thai text.

## 🎯 Project Goal

Build simple, useful, and accessible AI tools for everyone.

## ✨ Planned Features

- Text summarization
- Text improvement
- Thai-English translation

## 🌱 Project Status

Early development. Contributions and suggestions are welcome.

## 🤝 Contributing

Everyone is welcome to explore the project, share ideas, and help improve it.
